# Документация

Локальный анонимизатор юридических документов: находит персональные и идентифицирующие данные, заменяет их на теги вида `[ФИО1]` и восстанавливает исходный текст по таблице соответствий.

| Документ | О чём |
|---|---|
| [pipeline.md](pipeline.md) | Пайплайн: чтение → детекция → теги → замена → восстановление |
| [recognition.md](recognition.md) | Алгоритм распознавания: регулярки, NER, контрольные суммы, пересечения |
| [usage.md](usage.md) | Интерфейс, работа с LLM, форматы файлов, структура проекта, тесты |

Краткий обзор и команды запуска — в корневом [README.md](../README.md).
